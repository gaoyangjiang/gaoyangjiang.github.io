# Gaoyang Jiang · Academic Homepage

Academic homepage built with [al-folio](https://github.com/alshedivat/al-folio) and published with GitHub Pages.

Edit `_pages/about.md` and its Chinese counterpart for the biography, `_bibliography/papers.bib` for publications, and `_pages/cv.md` for the CV. The profile mark in `assets/img/gaoyang-mark.svg` can be replaced with a photograph later by changing `profile.image` in both about pages.

The GitHub Actions workflow builds the Jekyll site and deploys the generated files to the `gh-pages` branch. In repository settings, choose **Pages → Deploy from a branch → gh-pages / root**.

The project uses the upstream al-folio starter and retains its [MIT license](LICENSE).
