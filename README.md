# Gaoyang Jiang · Academic Homepage

Academic homepage built with [al-folio](https://github.com/alshedivat/al-folio) and published with GitHub Pages.

Edit `_pages/about.md` and its Chinese counterpart for the biography, `_bibliography/papers.bib` for publications, and `_pages/cv.md` for the CV. The profile photograph is `assets/img/gaoyang-profile.jpg`.

The GitHub Actions workflow builds the Jekyll site and publishes the generated files through GitHub Pages. In repository settings, choose **Pages → GitHub Actions** as the publishing source.

The project uses the upstream al-folio starter and retains its [MIT license](LICENSE).
